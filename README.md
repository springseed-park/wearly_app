# 🧥 Wearly: AI 옷차림 추천 앱

## 📋 프로젝트 소개
Wearly는 인공지능(AI)를 활용해서 날씨와 상황에 맞는 옷차림을 추천해주는 웹 애플리케이션입니다. 사용자와 대화하면서 맞춤형 코디를 제안하고, 이미지 생성 기능까지 제공합니다.

## 🌟 주요 기능

### 1. 날씨 기반 옷차림 추천
- 사용자의 지역 날씨 정보를 실시간으로 확인
- 기온, 습도, 날씨 상태에 따른 적절한 옷차림 제안

### 2. 이미지 분석
- 사용자가 업로드한 옷 사진 분석
- 코디에 대한 피드백과 개선 제안

### 3. AI 이미지 생성
- 추천된 코디를 실제 이미지로 생성
- 사용자 취향을 반영한 스타일링

### 4. 개인화 설정
- **성별**: 남성/여성/중성
- **지역**: 전국 17개 시도
- **대화 톤**: 친근한/재치있는/까칠한
- **선호 색상**: 개인 취향 색상 설정
- **신체 정보**: 키, 몸무게 (선택사항)

### 5. 코디 보관함
- 마음에 드는 코디 저장
- 과거 추천 기록 확인
- 저장된 이미지로 새로운 스타일 생성

## 🏗️ 프로젝트 구조

```
프로젝트/
├── App.tsx          # 메인 앱 컴포넌트
├── index.tsx        # React 앱 진입점  
├── index.html       # HTML 템플릿
├── constants.ts     # 상수 정의 (지역 목록)
├── types.ts         # TypeScript 타입 정의
└── services/        # 외부 서비스 연동
    ├── weatherService.ts    # 날씨 API 연동
    └── geminiService.ts     # Google AI 연동
```

## 💬 대화 톤 예시

앱은 3가지 대화 스타일을 제공합니다:

### 친근한 톤 (기본)
> "서울의 날씨를 분석해서 옷차림을 추천하고 있어요... 잠시만 기다려주세요! 😊"

### 재치있는 톤
> "오케이~ 서울 날씨 스캔하고 스타일 뽑아내는 중! ⚡"

### 까칠한 톤  
> "서울 날씨 분석해서 코디 짜는 중. 기다려."

## 📱 주요 기능 사용법

### 날씨 기반 추천 받기
1. 설정에서 지역 선택
2. "오늘 날씨에 뭐 입을까?" 물어보기
3. AI가 날씨 분석 후 코디 추천

### 이미지 분석하기
1. 📷 버튼으로 사진 업로드
2. "이 옷 어때?" 같은 질문하기
3. AI가 분석 후 피드백 제공

### 코디 저장하기
1. 마음에 드는 추천에 ❤️ 버튼 클릭
2. 보관함에서 저장된 코디 확인
3. 저장된 이미지로 새 스타일 생성 가능

## 🔧 주요 컴포넌트

### App.tsx
메인 컴포넌트로 전체 앱의 상태와 로직을 관리합니다:
- 채팅 인터페이스
- 설정 모달
- 이미지 업로드
- API 통신

### 모달 컴포넌트들
- **SettingsModal**: 사용자 설정 관리
- **HistoryModal**: 저장된 코디 보관함
- **ImageZoomModal**: 이미지 확대 보기
- **PermissionModal**: 위치 권한 요청

## 🎨 UI/UX 특징

- **반응형 디자인**: 모바일과 데스크톱 모두 지원
- **다크 모드**: 시스템 설정에 따른 다크 모드 자동 적용
- **빠른 답변**: 추천 답변 버튼으로 쉬운 대화

## 📝 상태 관리

앱은 React의 `useState` 훅을 사용하여 상태를 관리합니다:

```typescript
// 주요 상태들
- messages: 대화 내역
- region: 선택된 지역
- gender: 성별 설정
- tone: 대화 톤
- colors: 선호 색상
```

## 💡 초보자를 위한 팁

### React 이해하기
- React는 UI를 만드는 JavaScript 라이브러리입니다
- 컴포넌트 단위로 화면을 구성합니다
- 상태(state)가 변경되면 화면이 자동으로 업데이트됩니다

- 자동완성 기능이 향상됨
- 코드가 더 안정적이고 읽기 쉬움

### 코드 수정 시 주의사항

- API 키는 절대 코드에 직접 노출하지 않기
- 에러 처리 코드 확인하고 수정하기
